# AAP-72 Aulë

Desarrollo narrativo incorporado en A092 R07 y R08. Las cifras son estimaciones editoriales y la producción está cortada en 2026.

| Característica | Referencia |
| --- | --- |
| Introducción | 1972 |
| Producción | 1972–1992 |
| Vehículos nuevos de familia | 1600 |
| Masa de referencia | 31 t |
| Arma principal | Obús 155 mm |
| Armamento secundario | 12,7 mm |
| Dotación | 5 |
| Propulsión | Diésel 520 CV |
| Velocidad carretera y terreno | 55 / 30 km/h |
| Autonomía | 420 km |
| Blindaje | Acero 12–30 mm |

Es artillería autopropulsada; se mantiene fuera del total de carros y del universo de VCI y transportes.
