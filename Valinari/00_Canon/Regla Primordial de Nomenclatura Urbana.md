# Regla Primordial de Nomenclatura Urbana

Toda entidad urbana nueva usa el formato **Nombre ficticio (nombre real)**.

## Prioridad

1. Nombres de Tolkien, preferentemente sindarin.
2. Nombres relacionados con región, función, paisaje, linaje o tradición.
3. Nombres de *Juego de Tronos* como segunda reserva.
4. Nombres inventados solo con justificación lingüística, geográfica o histórica.

## Compatibilidad con el canon existente

No se repiten nombres ficticios completos. Las raíces compartidas pueden mantenerse si el calificativo histórico hace inequívoca la entidad.

No se crean sufijos geográficos artificiales para resolver duplicaciones. Se conservan, sin embargo, los nombres históricos ya adoptados: Calenardhon Austral, Pelargir Austral, Erellond Sur, Amon Rûdh Oriental y Calenport Sur.

## Formato

**Nombre ficticio (nombre real)**
