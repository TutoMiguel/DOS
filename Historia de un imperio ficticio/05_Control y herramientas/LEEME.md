# Control y herramientas

rutas_proyecto.json es la configuración de los comandos de esta carpeta. Verificar proyecto.ps1 es de comprobación; -Inventario actualiza el catálogo. Preparar Word para revision.ps1 genera un provisional con las rutas configuradas. La publicación de Word y PDF exige revisión de contenido y render. Las utilidades antiguas de otras carpetas se conservan como antecedentes y pueden contener rutas obsoletas.
