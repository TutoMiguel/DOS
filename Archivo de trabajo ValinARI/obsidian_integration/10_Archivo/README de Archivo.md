# Archivo histórico

Este archivo conserva versiones anteriores, enmiendas sustituidas y materiales de modelación. Nada de lo que contiene modifica el canon vigente salvo decisión expresa.

## Organización

- `Versiones anteriores`: cánones v12, v13, v14 y v15.
- `Enmiendas`: documentos de actualización y retcons anteriores.
- `Modelacion`: matrices, extractos, scripts y cálculos de trabajo.
- `Documentos editoriales`: DOCX y copias de presentación.

La fuente normativa vigente es [[../00_Canon/Canon V16 Maestro]].
